# wow!! a travel fare calculator
- calculates how much someone would need to pay based on the number of passengers, how far they'll travel, and a constant rate of 14.

# version 1

## input (what the program takes in)
- name of one/the passenger
- how far they will be travelling
- how many passengers are on board
## process (what happens behind the scenes)
- the program multiplies the variables to give you your output.
## output (what the program spits out)
- the travel fare/what you pay the driver!
## does it include data validation? (limits in place to make sure the fare is reasonable and realistic)
- nope!! not yet!
